# GHIST review — November 20, 2026

The reviewed code passes its automated checks, but the suite is **not ready for
an all-challenge final submission**. Several original inputs have been revised,
current final inference has not run, and frozen testing predictions for
Challenges 2, 3, and 8 show substantial scientific weaknesses. No competition
submission was made during this review. Passing tests cannot guarantee an
absence of bugs or establish inference accuracy.

## Repairs and verification

- Added a locked Python environment, missing pandas/joblib/dadi dependencies,
  setup instructions, and GitHub Actions for tests and critical static checks.
- Fixed sweep accessibility double counting, excluded inaccessible and fixed
  variants from scan statistics, enforced valid VCF coordinates, and removed a
  hardcoded testing chromosome from the background-sweep BED exporter.
- Hardened the secondary-contact fast VCF parser against malformed genotype
  layouts and invalid positions. It still explicitly requires the documented
  43/24 diploid population layout; another layout needs a compatible extractor.
- Updated Challenge 9 to the current ten accepted labels, repaired the
  single-class conditional-model case, canonicalized unordered IBD pairs, and
  validated labels before opening a frozen output for writing.
- Added local submission validation for all original 12 challenges: YAML keys
  and numeric bounds, testing/final sweep chromosomes, BED intervals, accepted
  relatedness labels, degree consistency, duplicate pairs, and optional exact
  input-pair coverage. This checks format and supplied coverage, not accuracy
  or input provenance.
- Corrected memory requests in 41 Slurm scripts to Betty's enforced partition
  rules. The review ran successfully as scheduled job **10847495**, exit 0.
- Changed downloads to pin an explicit Synapse version and preserve archived
  inputs, with entity, version, file-handle, size, and SHA-256 manifests.

The final code passed **153 tests** locally on macOS and in a fresh locked
Linux ARM64 environment on the additional compute host. The earlier review
also passed 153 tests on Betty in the original model environment; the final
parser/accessibility follow-up is queued there as job 10847766. Critical Ruff checks and `bash -n` on 149 shell files passed.
The warnings concern PyTorch's nested-tensor optimization; Betty also reports
an existing dependency deprecation warning. These checks do not rerun every
large-data inference, GPU workflow, or external program.

All **75 named source artifacts** checked against the historical freeze records
matched their SHA-256 values. This does not certify every raw input or the
unnamed Task 1 source-hash entries. See the committed
[verification records](../experiments/review_2026_11_20/).

August inventory and sealed final hashes therefore do not establish current
data provenance. The [metadata snapshot](../configs/synapse_versions_2026_11_20.json)

files. Their entity IDs are recorded in the challenge registry. Existing
historical Slurm paths deliberately still name archived inputs; point any new
run at the versioned current paths explicitly.
