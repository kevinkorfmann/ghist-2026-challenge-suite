# Low-coverage Tasks 13–14: development and validation

The two low-coverage challenges are active 2026 challenges, not hypothetical future work. They have separate testing and final submission evaluations on the [official demographic challenge page](https://www.synapse.org/Synapse:syn74803798/wiki/640740). They were not implemented by the existing twelve-task pipeline. This work adds a separate `ghist_lowcoverage` namespace and does not modify the methods other sessions are developing.

Task 13 asks for bottleneck age and post-decline size fraction from 20 diploid individuals at approximately 2× depth. Task 14 asks for split age and the two current population sizes from ten diploids in each of `pop1` and `pop2`, at approximately 4× depth. Both provide aligned, indexed BAMs, population labels, and a dataset-specific reference for a 10 Mb contig. Both specify mutation rate `1e-7` and recombination rate `1e-8` per base per generation. The BAMs/reference were regenerated in October; matching current versions matters.

Neither task is **scientifically qualified**. Task 13 fails recovery and stability checks. Task 14’s original six-cohort confirmation fails strict numerical stability despite good recovery; the cap200 full-window policy also fails stopping in both noise strata. Both cases in the separately authorized pragmatic cap500 development run now pass every unchanged development gate and the recorded practical criteria. Every old failure remains preserved, and no fresh confirmation was generated. Root independently audited all 990 evidence bindings and approved Task14 pragmatic final inference; this does not confer strict scientific qualification. The user subsequently requested submission of every remaining task despite validation status. Task13 is therefore reopened for a fixed, development-selected fallback package, with its failures explicitly retained. The new pipeline audits the full BAM roster, read-group sample identities, coordinate sorting, indices, reference and contig lengths. It uses ANGSD genotype likelihoods and site allele-frequency likelihoods. The original route estimates a folded spectrum with realSFS; the Task 14 stabilization experiment uses winsfs with a full 500-block window and folds jointly afterward. There are no hard genotype calls, SNP significance filter, or complete-case requirement. A sample with no reads contributes uncertainty rather than an invented genotype. The reference is used as a folding orientation, not assumed to be the ancestral sequence.

The two-population spectrum is folded jointly across populations. Between-population fixed differences remain available for demographic inference. Equal pooled-frequency complementary bins are symmetrized to match the `moments` folded-spectrum convention. Callable exposure is the sum of all realSFS bin counts, including monomorphic sites. That retained exposure, rather than an assumed complete 10 Mb, converts theta to ancestral population size. Demographic fits mask monomorphic corners and use eight starts each for L-BFGS-B (explicit log-coordinate difference step `1e-4`) and Powell. An interior successful solution must agree across methods in both parameters and objective. A better boundary/non-converged fit remains the reported best diagnostic and invalidates numerical acceptance; a worse interior fit cannot hide it.

The demographic models are a two-epoch decline and a split with constant descendant sizes and zero migration. Their nuisance ancestral size is estimated from theta; all times are converted using that ancestral size. These model assumptions require assessment on independent simulations before a release decision. The implementation includes an exact-template, hash-verified YAML formatter that returns a draft string, with no submission transport or challenge-data downloader. Formatting success does not authorize inference or submission.

Validation uses a separate msprime ancestry, paired 126 bp reads with independent per-individual start positions/errors, varying individual depths around the required mean, Q30 bases, and known correct alignments. The design is fixed at round values: ancestral size 10,000 for both; a 0.2 decline fraction at 2,000 generations for Task 13; descendant sizes 5,000 and 15,000 and split 5,000 generations ago for Task 14. Seeds are 731041 and 731059. These smoke cases test an actual BAM → likelihood → spectrum → demographic estimate, but perfect mapping, fixed quality and no indels do not reproduce BWA alignment biases or the organizer's complete read simulation.
