# Task 1 posthoc fixed-point diagnostic for development case 16

This diagnostic uses the existing 100 Mb development case 16 only, after its poor biological recovery was known. It compares two predeclared shape points per engine: the generating shape and the final selected endpoint. It runs no optimizer, grid search, new simulation, parameter tuning, model change, or holdout evaluation. Its purpose is to distinguish reproducible numerical fitting from recovery of the generating parameters. One realization and two shape points cannot establish identifiability, a global optimum, or general performance.

The generating parameters are 28,000 generations, ancestral effective size 21,000, and post-decline fraction 0.89. Therefore the true scaled time is 28,000/(2 × 21,000) = 2/3, the current effective size is 18,690, and theta is 4 × 3.42e-8 × 100,000,000 × 21,000 = 287,280. At both fixed shape points, each engine evaluates its archived `Inference.ll_multinom` score and profiles theta analytically, exactly as in production. Profiling theta at the true shape does not fix the ancestral size to its generating value.

The protocol was frozen before evaluation in `experiments/readiness_2026_11_20/bottleneck/stress_fixed_point_diagnostic/manifest.json`, SHA256 `2cd49edaac63b6025bd756b10c8c80a525e660e88136c3f5ed74b102346315ab`. It binds the spectrum, selected fit records, truth-context record, copied production source, four points, likelihood domain, runtime versions, and comparison tolerances. It uses the same folded 114-haplotype spectrum and original Betty environment as the final source replay (moments-popgen 1.6.0, dadi 2.4.4, NumPy 2.4.6, SciPy 1.16.3). Dadi retains grids 134/144/154. Runtime package versions are recorded; the copied project source is hashed, without claiming every third-party dependency file is hash-locked.

Slurm job 10856103 permits one CPU and five minutes. Full expected spectra and masks are saved with the four result records; selected-point scores and theta must reproduce the archived fits within 1e-8 absolute log-likelihood and 1e-12 relative theta. The separate audit script checks source/input/output hashes, the four-point denominator, identical active-bin domains, and the physical transforms N = theta/(4 mu L), generations = 2 N T, and N_current = nu N. No PR7 production file is changed by this diagnostic.

All four planned points completed and passed attestation. Slurm completed with exit code 0:0 in 17 seconds; the measured evaluation section took 6.15 seconds. Both points within each engine used exactly the same 57 active folded bins and 1,404,134 total observed counts. The selected-point likelihoods, theta values, and physical estimates reproduced the archived fits exactly.

The selected shape has a higher score than the generating shape by 9.801855 for moments and 7.555971 for dadi under these fixed likelihood implementations. At the generating shape, profiled theta is only 0.1651% and 0.1760% above the generating theta. At the selected shape, current-size products are only 0.5587% and 0.5921% above the true 18,690, despite ancestral-size estimates being 16.26 and 15.24 times the truth and times being 7.79 and 7.73 times the truth. The fractions are approximately 0.05505 and 0.05875 instead of 0.89. The physical transforms and both selected endpoint evaluations are internally consistent; no transform discrepancy was detected by these checks.

This case therefore preserves an explicit scientific failure after successful numerical verification: both engines prefer the selected incorrect history over the exact generating shape among the two evaluated shapes, while the current-size product remains close. The diagnostic does not determine why the observed spectrum gives that preference, show that any endpoint is globally optimal, or establish that current size is generally well recovered. It does not establish identifiability or nonidentifiability. These score differences are not converted into significance tests or confidence statements. Further method assessment would need independently designed recovery and calibration evidence, without choosing settings to recover this already inspected case. Task 1 remains scientifically unvalidated and not ready for release on the strength of these checks.
