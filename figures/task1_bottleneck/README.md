# Task 1 bottleneck validation figure

`task1_validation` compares exact whole-chromosome recovery on the 29 untouched
nominal evaluation cells and the observed estimates from six complementary
methods. Panels a and b show recovery against the identity line. Panels c and d
show observed point estimates; the blue interval is the 95% physical-block
bootstrap interval for the frozen moments SFS estimate. Open symbols indicate
secondary learned estimates, including the broad-prior score calibrator, and the
gray cross marks the translation diagnostic that was not eligible for selection.

Files are provided as vector PDF and SVG plus a 450 DPI PNG. Colors use the
Okabe-Ito palette, marker shape redundantly encodes method, and all typography
uses regular weight.
