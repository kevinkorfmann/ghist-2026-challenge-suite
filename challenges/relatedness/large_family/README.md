# Relatedness in one large family

Infer pairwise relationships from a phased, error-free human-family VCF.

The frozen solution blends a shallow histogram-gradient segment-shape model
with the calibrated forest, then permits only replicated same-degree pedigree
corrections. It reached 47.20% exact and 69.08% meiosis-degree accuracy across
eight untouched simulations, improving every replicate. No submission was made.
