# Large family with high background relatedness

Infer pedigree relationships while distinguishing recent pedigree IBD from elevated
population-level background sharing.

The frozen method estimates the unlabeled background length spectrum from the
cohort, trains on matched short-segment contamination, and uses pedigree topology
only when it agrees with the pairwise meiosis degree. On 20 untouched paired
comparisons, exact accuracy improved by 2.68 percentage points with gains in every
comparison.
