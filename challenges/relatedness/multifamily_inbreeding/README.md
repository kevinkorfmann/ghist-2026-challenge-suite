# Multifamily cohort with close inbreeding

Infer within-family relationships across eight unrelated dog families while allowing
close inbreeding.

The frozen solution combines HBD-masked pairwise spectra with family partitioning
and pedigree consistency. A richer degree-guarded spectrum model was rejected on
untouched simulations, so the 63.58% exact pair estimate remains unchanged. No
submission was made.
